# 🏅 120 Years of Olympic History Analysis

An interactive data analysis project built with Python and Streamlit to explore
Olympic Games data and discover patterns in medal performance, countries,
athletes, and Olympic events.

## 📌 Overview

This project analyzes Olympic history through an interactive Streamlit
dashboard.

Users can explore Olympic data through different analysis sections and
filter the information according to their requirements.

The project was developed to practice Python, data preprocessing,
data analysis, visualization, and Streamlit application development.

## ✨ Features

### 🥇 Medal Tally
- View medal statistics
- Filter analysis by year
- Filter analysis by country
- Explore Gold, Silver and Bronze medals

### 📊 Overall Analysis
- Explore overall Olympic trends
- Analyze participation and performance patterns
- Visualize important statistics

### 🌍 Country-wise Analysis
- Select a country
- Explore its Olympic performance
- Analyze medal-related information

### 🏃 Athlete-wise Analysis
- Explore athlete-level information
- Analyze individual Olympic participation and performance

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Streamlit
- Matplotlib
- Seaborn
- Data Analysis
- Data Visualization
